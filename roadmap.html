Phase 1

Toolchain & Environment Setup

Configure cross-compilation toolchain, binary utilities, emulator, and debugger.

Tools Required:
  • nasm (x86 assembler)
  • i686-elf-gcc & i686-elf-ld (bare-metal cross compiler)
  • qemu-system-i386 (x86 emulator)
  • gdb / gdb-multiarch (remote debugger)
Deliverables & Verifications:

Write a master Makefile to automate assembly, compilation, image generation, and launching QEMU with GDB stub enabled (-s -S).

Phase 2

Real-Mode Boot Sector (16-bit)

First code executed by BIOS at 0x7C00. Display a greeting message using BIOS interrupts.

Key Concepts:
  • Origin offset: [org 0x7c00], 16-bit mode: bits 16
  • BIOS Teletype output: int 0x10 (AH=0x0E)
  • Boot signature: exactly 510 bytes code + dw 0xAA55
  • Zeroing Segment registers (DS, ES, SS) & setting stack pointer
Deliverables & Verifications:

QEMU boots directly from the 512-byte raw binary and displays a custom startup message on screen without crashing.

Phase 3

Disk Loading & Real-Mode Interrupts

Read subsequent sectors containing the kernel from disk into RAM using BIOS disk routines.

Key Concepts:
  • BIOS disk service: int 0x13 (AH=0x02, CHS addressing)
  • LBA to CHS conversion (Cylinder, Head, Sector)
  • Carry Flag (CF) check for read error handling & retry loop
  • Loading destination buffer into memory (e.g. at 0x100000 or 0x8000)
Deliverables & Verifications:

Successfully load a secondary sector containing test data or kernel stub and verify contents in RAM via GDB inspect memory (x/16x 0x...).

Phase 4

32-Bit Protected Mode Switch

Unlock 4GB address space: enable A20 gate, define GDT, set CR0, and jump to 32-bit C kernel.

Key Concepts:
  • Enable A20 line (Fast A20 or keyboard controller)
  • Build GDT: Null, Kernel Code (0x08), Kernel Data (0x10)
  • Disable interrupts: cli
  • Load descriptor: lgdt [gdt_descriptor]
  • Set PE bit in cr0 (Protection Enable)
  • Far jump jmp 0x08:kernel_entry to flush CPU pipeline
Deliverables & Verifications:

Reach 32-bit entry point, reload data segments with 0x10, and write colored characters directly into VGA text buffer at 0xB8000.

Phase 5

Interrupts, Paging & Heap Memory

Establish protected mode IDT, remap 8259 PIC, enable 4KB paging, and create kmalloc/kfree.

Key Concepts:
  • IDT (Interrupt Descriptor Table) with 256 gates
  • Remap PIC (Master: 0x20-0x27, Slave: 0x28-0x2F)
  • ISRs (Interrupt Service Routines) & IRQ dispatching
  • Two-level Paging: Page Directory (1024 entries) & Page Tables
  • Load CR3 and flip paging bit in CR0
  • Heap memory management (block header/footer, buddy/free-list)
Deliverables & Verifications:

Catch division-by-zero or page faults cleanly without triple-faulting; dynamically allocate and free arbitrary memory structures via kmalloc().

Phase 6

Tasks, Processes & Multitasking

Implement process control blocks, hardware TSS, context switching, and round-robin scheduler.

Key Concepts:
  • TSS (Task State Segment) for Ring 0 stack switching
  • Process Control Block (PCB): registers, page directory, state
  • PIT (Programmable Interval Timer) IRQ0 timer tick
  • Assembly context switch (pushad / popad, stack pointer swap)
  • Cooperative and preemptive task scheduling
Deliverables & Verifications:

Run two concurrent tasks printing alternating characters or counters driven by the timer interrupt.

Phase 7

VFS, FAT16 & ELF Executable Loading

Read files from disk, parse 32-bit ELF binaries, and execute user programs in Ring 3.

Key Concepts:
  • VFS (Virtual File System) abstraction (open, read, write, close)
  • FAT16 file system parsing (Boot sector, FAT tables, Root dir, clusters)
  • ATA hard drive driver (PIO mode)
  • ELF32 file header & program header parsing
  • Ring 3 user mode transition via iret (CS=0x1B, DS=0x23)
  • System calls via software interrupt (e.g. int 0x80)
Deliverables & Verifications:

Load an external compiled C program from disk into a separate user virtual memory space and execute it securely.

Phase 8

Keyboard Driver & Interactive Shell

Capture user input with a PS/2 keyboard driver and run an interactive command line interface.

Key Concepts:
  • PS/2 Keyboard Controller: port 0x60 & IRQ1
  • Scancode set 1/2 translation to ASCII characters
  • Key buffer (ring / circular buffer)
  • VGA scrolling and cursor hardware movement (ports 0x3D4 / 0x3D5)
  • CLI parser (help, ls, run, clear)
Deliverables & Verifications:

Type commands directly into the QEMU window, list files on disk, launch user programs, and view program output.
